# 作品集網站：設計 Brief

> 狀態：概念與互動已定案，可開始實作。未定項目見第 10 節。
> 最後更新：2026-11-13

---

## 1. 核心概念

用一個互動，讓整個網站在兩種人格之間切換，呈現個人的**兩面性**。

- **高冷面**（預設）：精緻、克制、像高級品牌產品頁
- **Brain rot 面**：過載、刻意沒設計過、deep-fried 網路垃圾堆

**敘事**：籠子裡關著一隻寵物 = 被關起來的「鬧的那一面」。是**觀眾**親手放牠出來、親手拆穿高冷。

---

## 2. 切換機制（雙向、不對稱）

| 方向 | 互動 | 感覺 |
|---|---|---|
| 高冷 → Brain rot | 打開籠子，寵物衝出來 → 炸開彩色紙片 → 整頁翻轉 | 一瞬間、暴力、爽 |
| Brain rot → 高冷 | 抓住到處亂跑的寵物，塞回籠子關上 | 要花力氣、像在抓寵物 |

- 寵物在 brain rot 面會在頁面上亂跑（desktop pet 感）

### 寵物：Space Dog（已定）
- **造型**（依本人 3D 設定圖 `character-sheet.png`）：一大一小兩隻耳朵的太空狗
  - 深色是體色：頭、身體、腿、大耳背面
  - 紫色部位：大耳內側、小耳、眉、臉頰毛、手、腳
  - 橘色發光：眼睛、鼻子、肚子、尾巴三顆不相連的圓珠（離身體越遠越大）
  - 嘴巴是深色，平常看不到
- **配色**：深色 #1F1B33、紫 #7C63DB、橘 #FFA033；橘色部位加發光；深色身體外圍加一圈細亮邊（太空黑背景上輪廓才看得到）
- **製作方式**：分層向量 + **程式骨架**（不用序列圖）
  - `space-dog-parts.svg`：15 個部件，每個標好支點（data-pivot）與上層骨頭（data-parent）
  - 動作全部即時計算，所以能跟網頁互動：眼睛跟游標、抓起來甩、體力、撞籠子
  - 之後若要更細膩的表演，同一份 SVG 可匯入 Rive 重綁
- **高冷面**：平滑向量原貌
- **Brain rot 面**：同一隻狗套程式像素化濾鏡（低解析渲染 + 最近鄰放大 + 三色調色盤量化 + 透明度門檻 + 位置對齊像素格 + 降到 12fps；每格 4 CSS px）
  - **病毒模式**：時不時自動亂切視覺狀態，像壞掉或中毒（像素 / 深炸 / 色彩錯位 / 畫面撕裂 / 解析度崩潰 / 反相 / 閃回向量）
  - 切換瞬間：像素化由細到粗、帶深炸的「炸爛」轉場
- **原型**（已確認效果）：`prototypes/space-dog-rig.html`：待機呼吸、眼睛跟游標、眨眼、小跳步亂跑、抓起來甩動掙扎、放開掉落與落地擠壓、尾巴圓珠拖曳、像素化濾鏡與病毒模式
- **還沒做的動作 / 狀態**：逃離游標、體力與喘氣、撞籠子、被關在籠子裡的躁動、衝出籠子、被吸回籠子、爬上作品卡與彈窗
- **已淘汰**：舊的像素序列圖包（204 動作 / 29 atlas）：各包角色大小不一、非整數縮放造成漂移，不再使用

### 抓寵物回籠（已定）
1. **亂跑**：利用整個頁面，爬上作品卡、坐在彈窗標題列、從彈窗跳下、在格子間鑽
2. **追（體力制，不是次數制）**：游標靠近就加速逃、跳躍、假動作 → 被追幾秒後喘氣變慢 = 可抓時機 → 不追會恢復體力
   - 電腦版約幾秒到十秒，手機版更短
3. **抓到**：按住提起，在游標下晃動掙扎（物理感），游標變抓取手
   - 籠子有**吸附範圍**：靠近會發光、門自己打開，放開自動吸進去
   - 中途放手：掉下彈一下再跑，但仍是疲累狀態可馬上再抓
4. **回到高冷面：往內吸**：關進籠子瞬間，彈窗、彩紙、emoji 全被吸進籠子，meme sound 戛然而止，收縮回太空黑寂靜（與進場「往外炸」對稱）

- 籠子在 brain rot 面位置與高冷面相同，**永遠不被彈窗蓋住**
- 引導：籠子掛歪歪手寫紙條「請把我抓回來」+ 寵物偶爾回頭看籠子

### 三種出口的分工
| 出口 | 效果 | 風格 |
|---|---|---|
| 抓寵物回籠 | 回到高冷面 | 正規出口、要花力氣 |
| 「我放棄 😭」 | 留在 brain rot 面，彈窗全消失 | 免費、很醜很陽春 |
| Premium | 留在 brain rot 面，彈窗全消失 | 付費（信任制）、華麗有感謝動畫 |

- **「我放棄」只維持這次造訪，Premium 永久存在瀏覽器**（已定）→ Premium 有實質差別

### 籠子的位置與第一印象（已定）
- 籠子**一直浮在角落**，像 Windows 迴紋針小幫手那樣（不做「首頁旗艦產品發表」，避免焦點模糊成概念網站、也較好做）
- 兩面都是同一個角落位置
- 每次進站都從高冷面開始
- 不破壞高冷的提示（全視覺，高冷面靜音）：
  - 籠子掛一張小小的編輯風標籤「請勿打開。」（反向心理）
  - 寵物在暗處，眼睛跟著游標轉
  - 偶爾撞欄杆，籠子輕微震一下
  - 門閂每隔幾秒有金屬光澤掃過
  - 游標移到籠子上變抓取手
  - 待越久沒碰，寵物越躁動
- 手機：籠子與底部逃生門要錯開位置，不互相擋

## 3. 兩面視覺語言

### 高冷面
- 太空黑、有空間感（靠輕微視差 + 滑鼠微互動，不做 3D 場景）
- 玻璃質感 GUI、銀色邊框
- 暗黑雜誌編輯感：細襯線標題、字距拉開、做舊金屬質感、高冷距離感
- 參考：Apple 官網式的高級產品頁
- **聲音：全靜音**（頂多極細環境音）

### Brain rot 面
- 美學關鍵字：**Deep-fried internet / Anti-design / Web Brutalism / Web 1.0 · GeoCities / Glitch**
- 方向：不是精緻的手繪塗鴉，是幼稚、迷因、Roblox 網路文化、很鬧、ADHD brain rot
- 元素：
  - Win95/98 灰色厚邊視窗、藍色標題列、灰按鈕、像素系統圖示
  - WordArt 彩虹 3D 字、Comic Sans / Impact / Times New Roman，不管字距
  - 霓虹綠、亮黃、刺眼紅的垃圾橫幅
  - 施工中黃黑條紋、低畫質會抖的 GIF
  - JPEG 顆粒、過度飽和、鏡頭光暈的 deep-fried 迷因圖
  - 游標拖彩虹尾巴、到處亂彈的 emoji
  - 底部一堆礙眼的網頁小寵物跑來跑去
- 內容：**純垃圾廣告 + 自己喜歡的腦腐迷因圖**（不做針對作品的客製梗，太假掰）
- **聲音：meme sound**（參考 myinstants）、彈窗叮咚、寵物叫聲、廉價背景音樂
  - 放出寵物那下解鎖音訊（符合瀏覽器自動播放限制）
  - 必須有顯眼的靜音鈕（可做成很醜的按鈕）

## 4. 版面與作品

- **兩面共用同一套佈局**，只換風格層（同一個人、同一批作品，換人格皮）
- 高冷面：高級品牌產品頁式呈現，兼顧資訊閱讀效率與特別互動 / 遊戲性
  - 不要一件一件展覽式呈現（閱讀效率差）
- Brain rot 面：同佈局換 layout 風格 + 加上干擾物
- 作品內容與文案**兩面一樣**（不做兩套語氣，太 cringe）
- **隱藏款作品**：只在 brain rot 面出現（亂做的實驗、廢作品、私心作品）→ 放出寵物的實質獎勵

> 版面細節：本人仍在思考

### 內容架構（CMS）
- 參考：**YouTube、Viverse、Roblox** 這類內容平台的佈局（作品橫跨平面、影像、互動、遊戲）
- 結構：首頁總覽 → 點進去每件作品有**自己的詳細頁**
- 首頁容器（已定）：**混合式**
  - 最上方 bento 放 2–3 件代表作（Apple 感、高冷面門面）
  - 往下是平台式貨架或篩選網格
  - 前提：要好換皮
- 作品詳細頁：參考 YouTube 觀看頁 / Roblox 遊戲頁，**媒體區放最上面**，下方資訊，旁邊或下方「其他作品」
  - 影片：直接播放（嵌 YouTube/Vimeo 或自放影片檔，後者外觀最可控）
  - 遊戲 / 互動：Unity WebGL、Godot HTML5、網頁互動、itch.io 嵌入
  - 平面：可放大、可滑的圖片集
  - 可玩作品先顯示封面 + 「▶ 開始玩」，按了才載入
  - CMS 欄位「手機可玩嗎」：不支援的在手機改放示範影片
- Brain rot 面加料：播放 / 開始玩前先跳**不能跳過的假廣告**（「5 秒後可略過」倒數到 1 又跳回 5）
- 每件作品欄位：標題、類別、年份、角色、說明、圖、影片、外部連結
- 希望影片能直接在頁面播放、遊戲能直接在頁面上玩（iframe 嵌入）
- 旗標：「只在 brain rot 面出現」（隱藏款）
- 四語文字長度差異大（西文最長）→ 文字格子要能自適應或設字數上限

## 5. 垃圾彈窗系統

### 類型菜單
- 假中獎橫幅（「你中了 100 萬！」）
- 假防毒 / 系統警告
- 假下載進度條
- 「你是第 1000000 位訪客」
- **迴紋針小幫手梗**：brain rot 面籠子旁偶爾冒出「看起來你正在瀏覽作品集，需要幫忙嗎？」對話泡泡，選項全部沒用（同時提醒出口在這）
- **多重假叉叉型**：好幾個假的關閉鈕
- **小遊戲型**：要玩才能關
- **Reels 型**：可以真的滑短影音的彈窗
- 關閉鈕會像貓瑪利歐那樣閃躲

### 假叉叉陷阱
- 點到錯的叉叉 → 直接開超連結出去（像真的垃圾廣告），例如 LinkedIn
- 建議：**新分頁開啟**，作品集本體不消失
- 真正的叉叉存在但很難找

### 節奏建議
- 大部分一點就關（爽感）、少數卡人一下（記憶點）、混著來

### Premium 訂閱頁（贊助機制的惡搞）
- 模仿 YouTube Premium / 串流平台的訂閱方案頁，「訂閱即可免廣告」
- 實際上是「請我喝杯咖啡」的贊助機制
- **只存在於 brain rot 面**，高冷面沒有任何贊助按鈕
- 方案卡惡搞：Free（無限彈窗）/ Premium（一杯咖啡）/ Premium Ultra Max Pro（兩杯咖啡，內容一樣但你會覺得自己比較有錢）
- 「升級 Premium！」本身也是一個垃圾彈窗，而且是最難關的那個
- **機制（已定）：信任制真的免廣告**
  - 贊助完回到網站 → 「感謝訂閱 🎉」→ 彈窗從此消失（存在瀏覽器裡）
  - 不驗證是否真的付款，跳過付款也拿得到，無所謂
- 金流：用現成贊助平台（Ko-fi / Buy Me a Coffee / PayPal 等），網站不碰卡號；選收款到台灣方便的
- 與逃生門的關係：免費出路很醜很陽春，付費出路很華麗有感謝動畫

### 逃生門（確定保留）
- 最外層、很醜的陽春 HTML 預設字體：「我放棄 😭」

### Reels 彈窗（技術方向）
- 內容：純 brain rot 垃圾短影音，**不夾帶作品**
- 平台不提供「隨機推薦流」API，只能嵌入單支影片
  - TikTok：官方 oEmbed，丟連結拿嵌入碼
  - YouTube Shorts：iframe 播放器（外觀可控性較高，可藏控制列 / 循環）
  - IG：嵌入限制較多，優先度低
- 做法：**自己當演算法**，手動維護一份 brain rot 影片清單（JSON），自做上下滑容器逐支切換
- 注意事項：
  - TikTok 嵌入會帶官方外框，較難融入假彈窗風格 → 以 YouTube Shorts 為主較順
  - 原影片被刪會失效 → 載入失敗自動跳下一支、定期檢查清單
  - 只在彈窗打開時才載入，一次只載當前一支（效能、追蹤 cookie）
  - 各平台 iframe 自動播放聲音規則不同，需實測

## 6. 語言

- 支援：**中文、英文、日文、西班牙文**
- 偵測瀏覽器語言自動切換，非這四語一律英文；另放手動切換鈕
- **只翻正經內容**：導覽、功能 UI、作品標題與說明
- Brain rot 垃圾**維持混亂、不翻**（亂碼外文反而更真）
- 不用即時機器翻譯外掛（會破壞排版、字體）
- **上傳時自動翻譯**：在作品管理後台（CMS）上傳 / 存檔作品時，自動翻成四語填入對應欄位
  - 翻譯結果可手動修改，標記「機翻未校對 / 已校對」
  - 翻譯引擎：**輕量小模型**（本人決定），只需支援中英日西四語即可
  - 語言選擇理由：使用人口最多的語言 + 想接觸的國家
  - 網站前台只讀已存好的四語內容，不會動到排版

## 7. 手機版（已定）

**原則：輕量化但體驗完整**：全套 brain rot 體驗都在，互動改成觸控，各方面輕一點。

- **打開籠子**：點擊或拖曳門閂（不做搖晃，不跳權限請求）
- **抓寵物回籠**：按住抓起 → 拖到籠子放開；閃躲次數比電腦版少
- **閃躲叉叉**（手機沒有懸停）：點了叉叉跳到別處 / 視窗變大或分裂 / 假叉叉放在最易誤觸處
- **Reels 彈窗**：打開時鎖住背景捲動，接近全螢幕
- **彈窗密度**：同時出現數量少、間隔拉長，「擋路」不「封路」
- **逃生門**：固定在拇指點得到的底部，不被彈窗蓋住
- **視差 / 滑鼠微互動**：手機上減弱或關閉（手機沒有滑鼠懸停）

## 8. 3D / 空間感（已定）

- **不做 3D 場景、不做 WebXR**（避免為 3D 而 3D）
- 維持前面規劃的佈局（bento 代表作 + 平台式貨架 / 網格）
- 只加：**輕微視差 + 滑鼠微互動**
- Brain rot 面不做螢幕保護程式背景
- 參考作品：本人的 Ultimate Speed Test（VIVERSE）https://www.viverse.com/zh-TW/rtjhbKV

## 9. 已知風險 / 提醒

- **素材版權**：網路迷因圖、myinstants 音效多數有版權。作品集是公開的，上線前考慮自製 deep-fried 素材、找開放授權素材，或本機 demo 版與上線版分開
- **玻璃質感（backdrop blur）**：大量使用時手機效能負擔，需控制數量
- **煩的程度**：煩得好笑 vs 煩到關分頁，靠逃生門與新分頁開啟兜底
