# 作品集網站：交接包

給接手實作的人（或 Claude Code）。先讀 `DESIGN-BRIEF.md`，那是所有設計決定的來源。

## 這個網站是什麼

一個個人作品集，有兩種人格：預設是太空黑、玻璃質感的**高冷面**；訪客打開角落籠子放出寵物 Space Dog 後，整頁炸成 deep-fried 網路垃圾風的 **Brain rot 面**，滿是擋路的垃圾彈窗。把狗抓回籠子才會變回高冷面。兩面共用同一套佈局和同一批作品，只換風格層。

## 包裡有什麼

| 檔案 | 用途 |
|---|---|
| `DESIGN-BRIEF.md` | 完整設計決定：概念、切換機制、兩面視覺、作品與內容後台、垃圾彈窗、語言、手機版、未定項目 |
| `character/space-dog-parts.svg` | 寵物的分層向量。15 個 `<g>`，各有 `data-pivot`（關節座標）與 `data-parent`（上層骨頭），由後到前排列 |
| `character/character-sheet.png` | 寵物的 3D 設定圖（造型與配色的依據） |
| `prototypes/space-dog-rig.html` | 寵物的程式骨架原型，可直接用瀏覽器開。含待機、亂跑、抓起甩動、掉落、尾巴拖曳、像素化濾鏡、病毒模式 |
| `prototypes/dog-filter-lab.html` | 較早的濾鏡實驗（佔位角色），有格數與幀率的調整面板，可用來試參數 |

## 原型裡可以直接沿用的東西

`space-dog-rig.html` 的 `<script>` 是單一檔案的示範，實作時應拆成模組：

- **骨架**：`parts`（支點與父子關係）、`path`（各部件的路徑，與 SVG 相同）、`update()`（物理與姿勢）、`drawDog()`（依矩陣繪製）
- **像素化濾鏡**：`renderPixel()`：整個舞台以每格 4 CSS px 渲染到小畫布，經 `quantize()` 做透明度門檻與三色量化，再以最近鄰放大。位置先對齊格子再畫，所以不會漂移
- **故障效果**：`fried` / `split` / `slices` / `invert` 與解析度崩潰，由 `pickFx()` 依權重隨機切換
- **切換轉場**：格子由 2 → 3 → 4 px 逐步變粗，期間套深炸

原型的限制：只有正面一個角度；舞台是固定高度的一塊區域，正式版要改成覆蓋整頁、能站在 DOM 元素上；拖曳手感只在無頭瀏覽器驗證過能畫出來，沒有實際操作測試過。

## 建議的實作順序

1. **骨架站**：兩面共用的佈局（bento 代表作 + 平台式網格、作品詳細頁），先用假資料
2. **主題切換**：同一份 DOM 換兩套風格，確認換皮可行
3. **寵物模組**：把原型拆成模組，接上整頁座標
4. **籠子與切換流程**：開籠 → 炸開 → Brain rot；抓回 → 吸回 → 高冷
5. **垃圾彈窗系統**：先做兩三種，再擴充；逃生門和 Premium 一起做
6. **內容後台與四語**：上傳時翻譯
7. **手機版調整、聲音、效能**

## 注意事項

- 舊的 `space-dog-integration-handoff-v1`（像素序列圖包）已淘汰，不要使用
- 高冷面全程靜音；聲音要在訪客放出寵物的那次互動之後才能播放（瀏覽器限制）
- 籠子和「我放棄 😭」逃生門永遠不能被彈窗蓋住
- 尊重系統的「減少動態效果」設定
- 上線素材的版權見 Brief 第 9 節
