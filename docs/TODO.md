# 待辦:需要你人工處理的部分

程式能做的我會繼續做;這份只列**一定要你本人決定、提供、或在真機/帳號上操作**的事。
做完一項就把 `[ ]` 改成 `[x]`。後台指的是本機 `npm run dev` 之後的 http://localhost:3000/keystatic 。

---

## 1. 內容(後台填)

- [ ] **作品集名稱**:決定後填在「個人資料 → 名字」。全站(導覽列、頁尾、瀏覽器分頁標題、手機分頁列)都讀這一個欄位
- [ ] **個人資料**:職稱、一句話介紹、email(現在是 `you@example.com`)、社群連結
- [ ] **作品**:目前 6 件都是假資料,逐一換成真的
  - 標題、簡介、類別、年份、角色、內文
  - 封面圖(首頁卡片用)、圖片集、影片網址或可玩內容
  - 勾選 2–3 件「首頁代表作」
  - 決定要不要留「隱藏款」(只在 Brain rot 面出現的作品,範例是 `failed-experiment`)
  - 不要的假作品直接在後台刪掉
- [ ] **GIPHY 動圖**:後台「Brain rot 素材 → GIPHY 動圖」貼連結,10 張左右就夠。避開真人名人、政治、新聞
- [ ] **迷因圖**(選填):同一頁上傳自己的圖
- [ ] **Reels 短影音**(選填):貼 YouTube Shorts 網址。空的話這種彈窗不會出現
- [ ] **贊助連結**(選填):Ko-fi 與綠界網址。空的話 Premium 視窗會跳過付款步驟

## 2. 翻譯校對

- [ ] 個人資料與每件作品的英 / 日 / 西文翻譯:後台逐一檢查,改好後勾「已校對」(勾了之後自動翻譯不會再覆蓋)
- [ ] **日文**:Brain rot 彈窗的日文是我照日本廣告語氣寫的,建議請懂日文的人看一次(`src/interactive/junk-text.tsx`)
- [ ] 西文、英文的梗是否好笑,自己掃一遍即可

## 3. 真機測試(我只能在無頭 Chromium 裡測)

在 **iPhone Safari**、**Android Chrome**、**電腦 Safari / Firefox** 各開一次,看這些:

- [ ] 玻璃質感、星空背景、整體效能(會不會卡、手機會不會發燙)
- [ ] 3D 籠子:擺動、靠近時轉向、開門
- [ ] 換頁轉場(點作品卡 → 作品頁、返回)。Safari / Firefox 舊版沒有轉場是正常的
- [ ] 手機底部分頁列(含 iPhone 底部安全區域)
- [ ] 追狗的手感、抓狗會不會反白文字、長按會不會跳選單
- [ ] 電腦版分裂成三隻的時機(14 秒、30 秒)是否太快或太慢
- [ ] 彈窗密度:會不會太煩到想直接關網頁(這是平衡點,你決定)
- [ ] 音效音量
- [ ] 打地鼠小遊戲
- [ ] 四種語言各切一次

有問題截圖或錄影給我就好。

## 4. 上線(需要你的帳號)

- [ ] **合併到主分支**:目前所有改動都在 `claude/new-session-l9d633`。要我開 PR 就說一聲
- [ ] **Vercel**:匯入 repo、部署
- [ ] **線上後台(Keystatic GitHub 模式)**:照 README「部署」一節建立 GitHub App,在 Vercel 設定它要的環境變數與 `NEXT_PUBLIC_KEYSTATIC_STORAGE=github`
- [ ] **自動翻譯**:合併到主分支後,到 GitHub repo 的 Actions 頁面確認 `Translate content` 有跑、有權限 commit(Settings → Actions → Workflow permissions 要是 Read and write)
- [ ] **網域**(選填):買好後在 Vercel 綁定
- [ ] 綁了自己的網域的話,在 Vercel 加環境變數 `NEXT_PUBLIC_SITE_URL=https://你的網域`,分享連結時的預覽圖才會指向正確網址
- [ ] 上線後把網址貼到 LINE / Discord / X 看分享預覽圖(星空 + logo)正不正常

- [ ] 籠子 / 狗的造型:要換成你自己的設計就把檔案給我
- [ ] 音效全是程式合成的,沒有版權問題;字型都是 Google Fonts(開源授權)
